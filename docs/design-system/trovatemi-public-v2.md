# TROVATEMI PUBLIC EXPERIENCE v2

Status: **SUPERSEDED 2026-09-11 by `trovatemi-public-v3.md`**

This document supersedes the previous Proof Story / Beauty direct-response visual direction for the public website and diagnostic.

## Founder correction

The previous experience felt juvenile because it relied too heavily on:
- slogan stacking;
- stickers, stamps and visual gimmicks;
- “BAM / scene / story” pacing;
- oversized theatrical transitions;
- decorative pseudo-social objects;
- a quiz-like feeling instead of a professional diagnostic.

That direction is retired.

## Product impression

Trovatemi must feel like a serious local-business operator:

**direct, adult, commercial, verifiable, restrained.**

The public experience is not a game, a SaaS dashboard or a social-media creative stretched into a website.

## Core thesis

> **Il cliente ti sta già cercando. Il problema è che trova un altro.**

Supporting principle:

> **Chi cerca vale più di chi scrolla.**

The site should move from claim → evidence → mechanism → offer without theatrical filler.

## Visual system

### Palette
- Ink: `#0B0C0D`
- Paper: `#F5F3ED`
- White: `#FFFFFF`
- Signal yellow: `#F2BD18`
- Muted grey: `#6C6C68`

Yellow is a signal, not decoration.

### Typography
- Display: Anton
- Body: Archivo Variable
- No decorative serif in the core public experience.
- No handwritten typography.

### Layout
- generous whitespace;
- hard information hierarchy;
- large headlines only where they carry the argument;
- simple borders;
- no floating cards for decoration;
- no fake app UI;
- no ornamental gradients.

## Homepage contract

The homepage must answer:

1. What problem does Trovatemi solve?
2. Why does it matter now?
3. What does Trovatemi actually do?
4. What does it refuse to promise?
5. What does it cost?
6. What should I do next?

Current sequence:

```
thesis
→ operating principles
→ why search intent matters
→ real-case diagnostic
→ collect / reply / reuse mechanism
→ manual vs system
→ 21-day / €149 offer
→ Chris / final CTA
```

## Diagnostic contract

Public name: **Trovatemi analysis / diagnostic**, not “Beauty Check” as a product.

The internal route may remain `/beauty-check/` during the Beauty campaign.

Sequence:

```
intro
→ search real business
→ show public evidence
→ same-query context when defensible
→ five operational questions
→ deterministic diagnosis
→ three priorities
→ complete summary
```

No fake email capture in S01. Contact capture appears only when persistence and delivery are real.

## Evidence rules

Allowed:
- provider truth;
- same-query context clearly described as context;
- owner-declared process;
- deterministic diagnosis;
- verified product capability.

Never:
- invented ranking;
- invented benchmark;
- invented social proof;
- public 0–100 score;
- unsupported Google causality;
- review gating;
- promises of position.

## Copy rules

Use plain business language.

Good:
- “Questo è ciò che vede chi ti cerca.”
- “Il primo punto debole è la raccolta.”
- “Tre priorità. In quest’ordine.”
- “Il problema non è sapere cosa fare. È farlo con continuità.”

Retired:
- “BAM”
- “Famme vede’”
- “Mo”
- “Falla girà”
- “Beauty. Ma tosta.”
- “Peccato che Google non era lì” as a repeated theatrical motif
- playful labels that make the diagnostic feel like a quiz

## Offer truth

Current execution state:
- one product: Trovatemi;
- €149/month per location;
- 21-day trial;
- €0 during trial;
- payment method required at activation;
- cancel before renewal;
- no review gating.

## Acceptance

A public screen passes only if:
- a business owner can understand it without explanation;
- the strongest claim is verifiable;
- there is one obvious next action;
- it would not look childish in front of a serious €1M local business;
- removing a decorative element does not weaken comprehension.

If a screen needs gimmicks to feel interesting, rewrite the argument.
