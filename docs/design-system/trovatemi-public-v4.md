# TROVATEMI PUBLIC EXPERIENCE v4

Status: **CURRENT — founder direction 2026-09-11**

This supersedes `trovatemi-public-v3.md`.

## Founder correction

Trovatemi is not a Beauty product and the primary inbound is not a check/audit.

The supplied long-form campaign page is the reference composition for the public website. The public site should feel as close as practical to that reference while remaining a real responsive web page.

## Public brand

Primary brand: **TROVATEMI.IT**.

Core line:

> **Il passaparola che hai già. Messo al lavoro.**

No vertical label in the master brand.

## Homepage

The homepage is a campaign page, not a SaaS website.

Required visual sequence:

```
dark cinematic hero
→ huge black/white/yellow headline
→ strong CTA
→ white Google-choice section with phone visual
→ dark customer-proof section
→ collect / reply / reuse cards
→ white closing strip with proof → trust → choice
```

Typography, torn edges, yellow brush highlights, handwritten human-proof annotations and black/white/yellow contrast must stay close to the supplied reference.

## Inbound

Primary CTA:

> **CERCA LA TUA ATTIVITÀ**

Primary route:

> `/trova/`

The inbound is no longer a quiz or a multi-step diagnostic.

Flow:

```
campaign / local content / referral
→ trovatemi.it
→ cerca la tua attività
→ select real Google business
→ show current rating + review count
→ show up to 3 other results from the same query
→ explain the visible-proof situation without inventing a ranking
→ CTA: see how Trovatemi works / talk to us
```

The search itself is the personalization. No score. No 5-step check. No questionnaire before value.

## Evidence

Allowed:
- Google provider truth;
- selected place details;
- same-query context explicitly described as same-query context;
- deterministic arithmetic on visible facts.

Never:
- fabricated ranking;
- calling another same-query result the official competitor;
- invented benchmark;
- review gating;
- fake activation;
- fake proof or fake customers.

## Legacy

`/beauty-check/` exists only as a permanent redirect to `/trova/` so old links do not break.

Internal legacy file names may remain temporarily where renaming creates unnecessary risk, but no public UI, CTA, title or copy should frame Trovatemi as Beauty or as a check.
